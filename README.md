# 東京の街診断

10問の質問に答えると、あなたにぴったりの東京の街を診断するスマートフォン向けWebアプリです。
HTML / CSS / JavaScript だけで動作します（ログイン・データベース・外部APIなし）。

## 使い方

`index.html` をブラウザで開くだけで動きます。

スマホ実機で確認したい場合は、同じネットワーク内で簡易サーバーを立てるのが便利です。

```sh
python3 -m http.server 8000
# スマホから http://<PCのIPアドレス>:8000 を開く
```

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の構造（スタート / 質問 / 診断中 / 結果） |
| `style.css` | スマホ向けのデザインとアニメーション |
| `data.js` | 診断結果の街（8タイプ）と質問（10問）のデータ |
| `app.js` | 画面遷移・採点・結果表示・シェアの処理 |
| `scripts/check-balance.js` | 診断結果の偏りチェック（公開ページでは使いません） |

## 診断のしくみ

- 各選択肢に「街: 加点」が設定されていて、回答ごとに点数を合計します。
- 合計点が最も高い街が結果になり、2位の街が「相性のいい街」として表示されます。
- 同点の場合は、より多くの質問で加点された街を優先します。

## 質問の設計方針

最優先は **「4つのうち最低1つは、自分ならこれを選ぶと思えること」**。
性格を直接聞くのではなく、**生活の具体的な場面で、どう行動するか**を選んでもらいます。

- 4択は「4種類の人間」ではなく「4種類の自然な行動」にする
- 各質問に、家で過ごす・人に合わせるなど**誰でも選べる日常的な行動**を必ず入れる
- 一人・家族・恋人・友人・仕事など、いろいろな生活スタイルの人が選べるようにする
- 街の名物・有名スポット・イメージは選択肢に出さず、結果を予想しにくくする
- 「その他」「どれでもない」は使わない。クスッとする要素は「ちょっと分かる（笑）」程度まで
- 各選択肢は「メインの街に2点 ＋ 近い価値観の街に1点」
- どの街もメイン（2点）5回・サブ（1点）5回、合計15点ずつに統一

### 街ごとの価値観

| 街 | 価値観・行動のクセ |
| --- | --- |
| 下北沢 | 好きなものに一直線、ノリと勢い、お金より体験 |
| 代官山 | 自分の美意識、丁寧さ、身近な人と落ち着いて過ごす |
| 浅草 | 人とのつながり、誰かと一緒が楽しい、王道を楽しめる |
| 渋谷 | スピードと刺激、新しいもの・情報が好き、すぐ動く |
| 吉祥寺 | 無理しないバランス、現実的、まわりに合わせられる |
| 谷根千 | マイペース、急がない、なじみの場所と小さな発見 |
| 丸の内 | 段取りと合理性、用事を先に片付ける、確実さ |
| 中目黒 | 雰囲気と感性、お店選びへのこだわり、寄り道好き |

## 結果の偏りチェック

全回答パターン（4^10 = 約105万通り）を総当たりして、各街が結果になる割合を確認できます。

```sh
node scripts/check-balance.js
```

いずれかの街が 8% 未満、または 18% を超えると NG になります。質問や配点を変えたときは実行してください。

## カスタマイズ

質問や街を変えたいときは `data.js` だけを編集すればOKです。

- 街を追加：`TOWNS` に新しいキーで項目を追加し、質問の `scores` からそのキーに点数を入れる
- 質問を追加・変更：`QUESTIONS` の配列を編集する（問題数は自動で反映されます）
